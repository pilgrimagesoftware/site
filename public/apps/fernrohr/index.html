Fernrohr

Fernrohr is a desktop app for browsing and inspecting Kubernetes clusters. It reads your existing kube contexts and gives you a native interface for looking at resources without reaching for kubectl for every question.

Source on GitHub. Report issues or request features on the issue tracker.

What Fernrohr does

Fernrohr connects to the clusters defined in your kubeconfig and lets you browse and inspect their resources from a native macOS interface. It shells out to the system OpenSSH client to connect any kube context bound to an SSH tunnel, so no bundled SSH stack to configure separately.
