Settings

Knot's settings are organized into panes. Everything you set is persisted between launches.

  • General: whether Knot restores your layout and conversations on launch, keeps running in the menu bar, and other overall app behavior.
  • Appearance: light/dark/system appearance, fonts and sizes for the terminal, UI, and titles, Markdown font size, and Mermaid diagram theme and scale.
  • Coding: per-agent-type commands and options used when launching agents, and your source code base folder.
  • Keyboard: keybindings for Knot's commands.
  • MCP: whether Knot's local MCP server is enabled and which port it listens on, for agent-to-agent coordination.
  • Personas: reusable named instruction blocks you can hand to an agent. See the Personas page for more.
  • Prompts: saved prompt text you can reuse across agents.
  • Autopilot: whether Knot can automatically take a configured action (or run a custom prompt) on an agent's behalf, and which AI provider and API key it uses to decide.
  • Voice: voice input, including the voice engine, a push-to-talk key, and whether transcribed text is inserted automatically.
  • Bench: deployable agent templates you can spin up on demand.

Something not covered here? Let us know, or open an issue on GitHub.
