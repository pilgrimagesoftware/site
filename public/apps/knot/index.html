Knot

Knot is a desktop app for running and tying together multiple AI coding agents. Each agent gets its own session, status, and MCP connection, so you can run several at once and keep track of what each one is doing.

Source on GitHub. Report issues or request features on the issue tracker.

What Knot does

Each AI coding agent you run—Claude Code, Codex, Gemini CLI, GitHub Copilot, OpenCode, a shell, or a custom command—runs inside Knot's own interface rather than a bare terminal window. Knot tracks whether each agent is working, idle, awaiting input, or in an error state, and gives agents a way to message each other and coordinate through a local MCP server.
