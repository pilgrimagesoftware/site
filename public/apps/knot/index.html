Knot

Knot is a desktop app for running and tying together multiple AI coding agents. Each agent gets its own terminal session, workspace, status, and MCP connection.

Source on GitHub. Report issues or request features on the issue tracker.

What Knot does

Each AI coding agent you run—Claude Code, Codex, Gemini CLI, GitHub Copilot, OpenCode, a shell, or a custom command—gets its own terminal session inside Knot. Knot tracks whether each agent is working, idle, awaiting input, or in an error state, and gives agents a way to message each other and coordinate through a local MCP server.

Agents and workspaces

An agent is a terminal session bound to a launch configuration (which CLI to run and how). A workspace groups agents together, usually around a single repository or project. You can create, rename, select, close, restart, and reattach both agents and workspaces.

Knot discovers Git repositories and their linked worktrees, and surfaces Git status, diffs, and change statistics for each one, so you can see what an agent has changed without leaving the app.

Agent status

Every agent shows a live status so you can tell at a glance which ones need your attention:

  • Working: the agent is actively running.
  • Idle: the agent is waiting with nothing in progress.
  • Awaiting input: the agent needs a response from you before it can continue.
  • Error: the agent has hit a problem.

Coordinating multiple agents

Knot runs a local MCP server so agents can message each other and share context instead of working in isolation. This is useful when you want to split a task across several agents, or have one agent hand work off to another.

Settings and personas

Agents, workspaces, personas, and app settings are persisted between launches, so your setup is there the next time you open Knot.

Supported agents

Knot can launch Claude Code, Codex, Gemini CLI, GitHub Copilot, OpenCode, a plain shell, or any custom command you configure.

Installing on macOS

Knot is currently unsigned. After installing it in /Applications, macOS will block it from launching or from making network connections until you remove the quarantine flag and ad-hoc sign it:

xattr -d com.apple.quarantine "/Applications/Knot.app"
codesign --force --deep --sign - "/Applications/Knot.app"

Something not covered here? Let us know, or open an issue on GitHub.
